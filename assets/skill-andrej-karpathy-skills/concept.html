# 编码准则

1. 编码前先想清楚

不确定就先问，不凭空假设需求。

2. 简单优先

能用简单方案解决就不加抽象。

3. 精准修改

只动和任务相关的代码，不顺手重构。

4. 可验证的目标

先定义怎样算完成，再一步步验证。
