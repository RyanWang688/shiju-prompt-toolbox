MOTION ANALYSIS / AFTER EFFECTS

llc-pv-skill（PV 与角色动画复刻）

面向文字 PV、角色动画与 MV 复刻：按约 20 秒自然分段，逐镜解析排版、角色表演与运镜，支持角色替换与可选 L2D 绑定。

v0.4.0-alpha.2 Python + FFmpeg + AE MCP MIT 开源许可
01 · 全片观察与 20 秒自然分段结合 FFmpeg/ffprobe 与参考节奏切分段落，梳理文字动效、空间层次与角色表演结构。
02 · 逐镜脚本与素材核对输出逐镜参数清单，校验字体、角色图层、音乐卡点与可选 Live2D 绑定素材。
03 · AE 制作与三轮全片对照通过 Node.js 24+ 与 AE MCP 驱动 After Effects 分段合成，并执行三轮全片回看校准。
适用范围需自备参考视频、字体与素材授权；基础观察依赖 Python、FFmpeg 与 ImageMagick。
